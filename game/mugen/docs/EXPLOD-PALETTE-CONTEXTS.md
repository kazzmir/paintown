# Common-resource and helper Explod palettes — M4dd

Target: supplied M.U.G.E.N 1.1 beta1. This extends M4dc's character-resource
creation palette study. Original native inputs, captures, configurations,
resources, expectations and failed diagnostics remain immutable.

## Native evidence

42 accepted programs capture 504 numeric values: 36 context controls and six
wildcard-map follow-ups. Full parser verification checks state headers, constants,
controller kinds, triggers, parameters and every inherited AIR/CMD/stage byte.
All native numeric/color/consumer rows and five review sheets were inspected
before their separate promotion once. The original common-spark thumbnails
clipped some islands, so an additional full-effect sheet was reviewed before
promotion. The comparison crop contains all 918 spark pixels.

Common-resource animations default to owned palettes. Explicit ownpal=0 follows
both initial and later local PalFX, while default/one ignore it. AllPalFX still
acts globally. The stock common bank's forced-remap controls remain unchanged;
this does not establish arbitrary custom common-bank mapping behavior.

Shared-palette helpers cannot install local PalFX, although their expressions
still evaluate. Root PalFX reaches a shared helper's shared Explod; owned effects
remain independent. Owned helpers can install their own PalFX. Initial root
mappings survive both helper/effect ownership combinations. Later helper remaps
reach shared Explods and leave owned ones unchanged. These agree with the earlier
helper/PalFX consumer, rather than requiring a new helper palette model.

Initial PalFX distinguishes integer coercion: .9+0.0 gives shared ownership,
1.9+0.0 gives owned. Forced group -1 preserves prior maps. Other forced mappings
replace the inherited mapping state, including wildcard mappings: identity,
invalid destination and color-depth mismatch show base palette; valid 1,3 shows
palette three. Invalid destinations must not leave the earlier map active.
A single remap component is accepted and also gives base palette in this corpus;
its omitted second component remains ambiguous because invalid zero and identity
one yield the same visible result.
