# Actor sprite order

M4ap compares fourteen native programs: 156 numeric observations, one load
rejection, thirteen native foreground-color identities and 70 input hashes.
M4ao's overlapping actors expose a different foreground facing. Original solid
RGB markers isolate ordering from character art,
palette remapping, texture edges and animation timing.

Native draws higher SprPriority in front. Equal priorities put the lower world
entity ID in front, crossing root/helper ownership. A helper with priority 2
draws over the other root at priority 1. Roots at equal priority select P1;
equal root/helper priority selects the root. Moving a helper from priority 2
to -2 makes its root visible again. The corrected reversed-birth control changes P2 to A in state 0, before
creation. Its helper gets ID 58 and draws in front of P1's ID 59. The first
draft changed P2 to A too late and did not actually reverse creation; that
initial run is retained only as a diagnostic.

Two real pre-fix Go captures show green instead of the native red root tie
or higher-priority blue helper. See temp/m4ap-before-comparison.json and
app-runs/actororder-{roots,cross}-before-go/. The old renderer recursively
draws each root's family, ignores global SprPriority and draws P2 last.

The new shared actor list sorts across families and carries each entity's
root sprite-bank owner. Fight projection and the standalone player renderer
consume it. Effects retain their existing scene compositor; this does not
establish effect/actor/stage priority interleaving or proper projectile order.

The bank is original 32x32 solid RGB data generated by
tests/generate_actor_markers.py. Its four raw true-color sprites are red, green,
blue and yellow, with axes (16,32). No Elecbyte art is copied. The first bank
draft used incorrect version bytes and native rejected loading; the corrected
version matches the supplied compiler's accepted SFF v2 header. That rejected
draft is only diagnostic evidence under temp/, not an intentional golden.

SprPriority accepts the measured +/-99 values outside the documented -5..5
range and keeps their ordering. A literal float rejects loading; a computed
float truncates; bottom becomes zero at this parameter boundary. The typed
controller validates before mutation and does not change unrelated integer
controllers. The pre-fix boundary comparison passes twelve of fourteen and
fails only bottom/float cases in temp/m4ap-before-priority.log. All fourteen
pass in m4ap-final-actor-race.log; headless engine/evaluator races also pass.
Full races pass in m4ap-full-race.log (Match 172.121 seconds). Three fresh
native color/order/rectangle replays and the literal-float rejection pass under
temp/reference-runs/m4ap-replay-*. All final actual Go windows pass the capture and foreground-color checks.

Twenty real 1280x720 captures pass provenance/dimension/nonblack/runtime/resource
checks. All thirteen accepted actororder-*-go-final scenes match native foreground
RGB/identity; eight pure-color rectangles match exactly and five flipped scenes
retain the independently measured edge gap (native 9,120 versus Go 9,216 pixels).
The real-art scene at temp/app-runs/actororder-real-overlap-go/ (3/5/7 seconds)
reduces clothing-mask differences from 12,036 to 408 pixels, with correct
foreground facing. Native/Go white counts remain 22,362/22,626. Stock recovery at
actororder-stock-throw-go/ (2/3/4/7) retains two fighters without dust clones.
This is ordering/smoke evidence, not full framebuffer parity. Native debug magenta,
background/HUD/filtering and flipped edge sampling remain open. Measurements:
temp/m4ap-app-comparison.json.

The permanent tests/actor_render_probe.py checks all source/marker/executable
recipe hashes, numeric observations, captured PNG hash, foreground identity,
pure-color bounds and counts. The goldens retain native 9,216/9,120 exact-color
rectangles independently of the Go sorting implementation.

The solid markers independently expose flipped horizontal edge sampling:
unflipped red has 9,216 exact-color pixels at [592,444,688,540), while flipped
green/yellow have 9,120 at [593,444,688,540). Native column 592 blends the back
actor and column 688 blends the background; foreground interiors are exact.
This is separate from actor order and agrees with the earlier clipped-right
edge gap. Full native vertex/filter calibration remains open. No arbitrary
one-pixel position correction is introduced by this checkpoint.

M4aq subsequently isolates game-pixel flip phase and floors draw axes while
preserving CNS fractions. The real-art mask differences and reverse-helper
rectangle now match exactly; SPRITE-ALIGNMENT.md records 28 independent rasters
and the four sparse one-channel corner differences. Original M4ap captures
remain historical evidence rather than the current renderer result.
