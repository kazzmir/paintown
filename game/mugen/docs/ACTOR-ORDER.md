# Actor sprite order

Native draws higher SprPriority in front. Equal priorities put the lower world
entity ID in front, crossing root/helper ownership. A helper with priority 2
draws over the other root at priority 1. Roots at equal priority select P1;
equal root/helper priority selects the root. Moving a helper from priority 2
to -2 makes its root visible again. The corrected reversed-birth control changes P2 to A in state 0, before
creation. Its helper gets ID 58 and draws in front of P1's ID 59. The first
draft changed P2 to A too late and did not actually reverse creation; that
initial run is retained only as a diagnostic.

Two real pre-fix Go captures show green instead of the native red root tie or
higher-priority blue helper. The old renderer recursively draws each root's
family, ignores global SprPriority and draws P2 last.

The new shared actor list sorts across families and carries each entity's
root sprite-bank owner. Fight projection and the standalone player renderer
consume it. Effects retain their existing scene compositor; this does not
establish effect/actor/stage priority interleaving or proper projectile order.

The bank is original 32x32 solid RGB data generated by
tests/generate_actor_markers.py. Its four raw true-color sprites are red, green,
blue and yellow, with axes (16,32). No Elecbyte art is copied. The first bank
draft used incorrect version bytes and native rejected loading; the corrected
version matches the supplied compiler's accepted SFF v2 header.

SprPriority accepts the measured +/-99 values outside the documented -5..5 range
and keeps their ordering. A literal float rejects loading; a computed float
truncates; bottom becomes zero at this parameter boundary. The typed controller
validates before mutation and does not change unrelated integer controllers. All
final actual Go windows pass the capture and foreground-color checks.

The solid markers independently expose flipped horizontal edge sampling:
unflipped red has 9,216 exact-color pixels at [592,444,688,540), while flipped
green/yellow have 9,120 at [593,444,688,540). Native column 592 blends the back
actor and column 688 blends the background; foreground interiors are exact.
This is separate from actor order and agrees with the earlier clipped-right
edge gap. Full native vertex/filter calibration remains open. No arbitrary
one-pixel position correction is introduced by this checkpoint.

M4aq subsequently isolates game-pixel flip phase and floors draw axes while
preserving CNS fractions. The real-art mask differences and reverse-helper
rectangle now match exactly; SPRITE-ALIGNMENT.md records 28 independent rasters
and the four sparse one-channel corner differences. Original M4ap captures
remain historical evidence rather than the current renderer result.
