# Explod creation palettes — M4dc

Target: supplied M.U.G.E.N 1.1 beta1. This checkpoint covers character-resource
Explod palette creation and its expression phases. Common-resource defaults,
helper issuers, creation transparency/angles/randomness and pool admission remain
separate obligations. Source routing counts are not an overall coverage measure.

## Native evidence

63 original programs: 56 accepted, seven schema rejections, 672 captured numeric
values. All numeric/color/consumer rows and five native review sheets were
inspected before expectations were promoted once. Original inputs, recorders,
captures, resources and expectations remain immutable. Both configuration
ledgers exactly reconstruct FirstRun 1 to 0 and LF to CRLF finalization.

The default/zero ownpal shares the issuer palette. Nonzero values (tested 1/-1)
copy the current mapping, clear initial local PalFX and ignore subsequent issuer
PalFX/remaps. AllPalFX still affects both through global composition. Forced
remappal affects only owned character-resource palettes, although its expressions
also evaluate with ownpal=0. Group -1 disables the forced mapping without
suppressing evaluation of its second expression. Invalid destination controls
start from an unmapped palette; behavior over an existing map is not established.

Palette fields have an earlier expression phase than other creation parameters:
anim, ownpal, remappal group, remappal item, then the animation availability gate,
then id/facing/vfacing/position. Native assignment traces are 15672348 with a
valid action and 1567 with a missing action. Ownership uses its previously
computed value even when remappal changes the same variable. Bottom values
coerce to zero. Shadow remains behind the animation gate, as measured in M4da.

Bare float literals in ownpal/remappal, unknown ownpal triggers, malformed remaps
and excess remap components reject at load even when ownership is disabled.
Runtime float expressions and a one-component remap are accepted. The single
component control does not distinguish the omitted second component's value.

The visible consumer uses original KFM sprite 9000,0, whose SFF header identifies
palette 1,1. Distinct native portrait hashes prove remapping actually changes
that sprite. Crops compare all 508,800 RGB pixels with zero tolerance; snapshots
exclude clipboard/HUD text and freeze the world at state time eight.
