# Explod creation drawing — M4de

Target: supplied M.U.G.E.N 1.1 beta1. This adds creation-time angle, xangle,
yangle, transparency/alpha and conditional priority evaluation to the earlier
palette, motion, binding, ordering and shadow work. Other fields/pools and earlier
strict renderer differences remain open. Source routes are not full coverage.

## Native programs and boundaries

47 original programs: 42 accepted, five load rejections, 504 captured numeric
values. All numeric/color/consumer rows and five native review sheets were
inspected before separate promotion once. Full state headers/constants,
controller kinds/triggers/parameters and all AIR/CMD/stage bytes were verified
before copying/freezing/native observation. Three programs use the 1.0 profile.
Every native configuration exactly finalizes FirstRun 1 to 0 and LF to CRLF.

Creation evaluates position, scale, angle, yangle, xangle, priority, shadow and
alpha in the measured relative order. Native FVar storage rounds the assignment
trace to 123456792; checking all 362,880 permutations of nine unique labels
identifies 123456789 uniquely. A missing action skips these late parameters.
Palette expressions retain M4dc's earlier gate. Ontop suppresses priority
expression evaluation, as well as overriding its rendering placement.

Unspecified/default transparency preserves the AIR element's blend; none
forces opaque drawing, sub overrides with subtraction. Add/add1/addalpha use
source/destination defaults 256/256, 256/128 and 256/0. One alpha component changes
the source while retaining that mode's destination default. Runtime floats
truncate to integers; bare float alpha values and excess components reject.
Bottom alpha becomes zero, yielding an invisible object that still counts.

Recognized default/none/sub modes compile and evaluate alpha even when drawing
does not consume it. An absent or unknown mode skips alpha compilation/evaluation,
including unknown triggers. Quoted "add" is also ignored: the quotes are not
removed in this parser. This rule must not be copied from the standalone Trans
or ModifyExplod implementation without separate native proof.

Native quarter-turns retain 4,284 visible portrait pixels. The 1.5-degree case
has 4,422 pixels; 45 degrees has 4,495; combined 3D has 4,109; xangle30 has 3,966;
yangle30 has 3,679. Every complete body lies inside the strict comparison ROI.
The three 1.0 scenes match their corresponding 1.1 scenes. All colors and full
geometry were reviewed, including the source-alpha-one case's 1,611 faint pixels.
