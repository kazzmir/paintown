# Compatibility scope

Target: Elecbyte M.U.G.E.N1.1 beta1. Use [PROGRESS.md](PROGRESS.md) for the single
current completion checklist and actual missing/partial features.

The current engine supports stock one-on-one matches, compiled authored states,
combat/recovery, projectiles/helpers/bindings, effects, sound and round/rematch
flow. Full modes/teams/AI/BGM/assets/platform compatibility remains work.

All 89 documented controller families are registered; some have concrete incomplete
schemas or consumers.120 of127 trigger families have runtime routes. Registration
and route presence are not complete behavioral conformance. The coverage command
checks the current source and reports those gaps directly.

Existing detailed renderer/audio findings remain open where recorded. Pixel or
parameter matrices are not repeated for unrelated state-machine changes.
The completed segment contracts in the progress ledger are the normal validation
boundary. Earlier exhaustive tables and dated results are retained in Git history;
optional topic notes remain background rather than required implementation steps.
